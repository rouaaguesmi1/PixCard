# PixCARD: Unified Credit Risk API 
![Opera Instantané_2025-07-06_125907_127 0 0 1](https://github.com/user-attachments/assets/68073cfc-1598-471f-9ce0-180effcba8ee)


This project contains a self-contained, unified Python script that builds, trains, and serves a suite of machine learning and deep learning models for credit risk assessment. The application uses **FastAPI** to create a robust web API and trains all necessary models from scratch using **XGBoost**, **Scikit-learn**, and **PyTorch**.

The script is designed to be fully reproducible: on the first run, it will automatically train and save all models; on subsequent runs, it will load the pre-trained models for immediate use.

## 🚀 Key Features

*   **End-to-End Solution:** A single script handles data preprocessing, model training, saving, loading, and API serving.
*   **Multi-Model Architecture:** Implements a suite of models for different business needs:
    *   **PD Model:** Core Probability of Default prediction (XGBoost).
    *   **QuickScore Model:** A lightweight model for rapid pre-screening (Logistic Regression).
    *   **Archetype Classifier:** A multiclass model to segment customers (XGBoost).
    *   **Anomaly Detector:** A deep learning model to detect unusual data patterns (PyTorch Autoencoder).
*   **Modern API Framework:** Built with **FastAPI** for high performance and automatic interactive documentation (Swagger UI).
*   **Reproducible Environment:** Automatically trains models if they don't exist, ensuring a seamless setup.

## 📊 Dataset

The models are trained on the `sme_synthetic_credit_data_FULL.csv` dataset. This dataset must be present in the same directory as the script. It is generated by the `generatefinal.py` script.

## 🛠️ Models Trained from Scratch

The application automatically trains and saves the following models:

1.  **PD Model (`pd_model.pkl`):** An `XGBClassifier` trained to predict the `default_in_12_mo` target. This is the core credit risk model.
2.  **QuickScore Model (`quickscore_model.pkl`):** A `LogisticRegression` model trained on a small subset of highly predictive features for fast screening.
3.  **Archetype Classifier (`archetype_classifier.pkl`):** A multiclass `XGBClassifier` trained to predict the business `archetype` (e.g., "Stable Manufacturer", "High-Growth Tech Startup").
4.  **Anomaly Detectors (`autoencoder_archetype_*.pth` & `anomaly_artifacts.pkl`):** A set of **PyTorch Autoencoders**. A separate neural network is trained for each business archetype to learn its "normal" data patterns. These are used to detect fraudulent or inconsistent data.

## ⚙️ Prerequisites

Before running the API, you need to install the required Python libraries.

```bash
pip install "fastapi[all]" scikit-learn pandas xgboost joblib torch
```
*Note: `fastapi[all]` conveniently installs FastAPI, Uvicorn, and other dependencies.*

## ▶️ How to Run

1.  **Place the Dataset:** Make sure the `sme_synthetic_credit_data_FULL.csv` file is in the same directory as the Python script.
2.  **Save the Script:** Save the code as `unified_credit_api_pytorch.py`.
3.  **Run the Application:** Execute the script from your terminal.

    ```bash
    python unified_credit_api_pytorch.py
    ```

### What Happens on First Run
The script will detect that the model files (`.pkl`, `.pth`) are missing. It will automatically:
1.  Load and preprocess the CSV data.
2.  Train all four types of models described above.
3.  Save the trained models and artifacts to disk.
4.  Start the FastAPI web server.

This initial run will take several minutes due to the training process.

### What Happens on Subsequent Runs
The script will find the existing model files, skip the training step, and immediately start the web server, which will be much faster.

## 📚 API Documentation & Endpoints

Once the server is running, you can access the interactive API documentation (Swagger UI) in your browser at:
**[http://127.0.0.1:8000/docs](http://127.0.0.1:8000/docs)**

The API provides the following endpoints, organized by function:

### 1. Quick Screening

*   **`POST /screening/quickscore`**
    *   **Purpose:** Provides a fast, high-level risk indicator ("Low", "Medium", "High") based on a few key input features. Ideal for initial lead qualification or pre-screening.
    *   **Model Used:** `quickscore_model.pkl` (Logistic Regression).

### 2. Credit Decisioning

*   **`POST /decisioning/predict-pd`**
    *   **Purpose:** Calculates the precise Probability of Default (PD) for an SME using the full set of features.
    *   **Model Used:** `pd_model.pkl` (XGBoost).

### 3. Customer Analytics

*   **`POST /analytics/classify-archetype`**
    *   **Purpose:** Classifies an SME into a business archetype (e.g., "Stable Manufacturer"). Useful for targeted marketing and portfolio management.
    *   **Model Used:** `archetype_classifier.pkl` (Multiclass XGBoost).

*   **`POST /analytics/detect-anomaly`**
    *   **Purpose:** Identifies SMEs with unusual or inconsistent data patterns that may indicate fraud or data quality issues.
    *   **Model Used:** The script first uses the Archetype Classifier to determine the SME's group, then uses the specific PyTorch Autoencoder trained for that group to calculate a reconstruction error. A high error indicates an anomaly.

### 4. Fraud Detection

*   **`POST /detect/fraud`**
    *   **Purpose:** A simplified endpoint designed to check for potential application fraud based on metadata and common fraud patterns.
    *   **Model Used:** This endpoint currently uses rule-based logic for demonstration but can be extended with a dedicated fraud classification model.
